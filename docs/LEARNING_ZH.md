## 2. 班车：先明确事件顺序，再写 Bellman 方程

状态 `s` 是本期决策时已经在等车的人数，范围 0 到 200。动作 `a=0` 等待，`a=1` 发一辆容量 15 的班车。先观察人数、决定发不发车、上车，再对剩下的人收费，最后才有新乘客到达。

定义发车后剩余人数

```text
q(s,a) = max(s - 15a, 0)
c(s,a) = 100a + 2q(s,a)
s_next = min(q(s,a)+A, 200),   P(A=1,...,5)=1/5
```

报告的价值是需要最小化的**正成本**，不是负成本或奖励。空车和未满载发车都允许，固定成本都是 100。每期最多一辆车。新到达乘客本期不收费。超过 200 的人数裁剪掉，不另收溢出成本；这是明确的计算模型假设。

有限期的终端值取 `V_500(s)=0`，然后倒推：

```text
V_t(s) = min_a [ c(s,a) + 0.95 E[V_(t+1)(s_next)] ]
```

这里 Enumeration 枚举的是每个状态的 2 个动作和 5 个到达分支，通过动态规划重复利用子问题；没有指数级遍历全部 500 步完整轨迹。这是缺少课堂进一步定义时明确声明的实现选择。

无限期 VI 重复同一个 Bellman 更新直到最大变化不超过 `1e-10`。PI 则交替做固定策略的线性方程求值和每个状态的贪心改进。PI 的求值式是 `(I-gamma P_pi)V_pi=c_pi`。

实测最优策略是 0 至 12 人等待，13 至 200 人发车。阈值小于容量 15 并不矛盾：多等几个人可以提高装载率，却也产生等待成本。阈值是算法逐状态求出的，没有预先强加阈值形式。

## 3. REINFORCE：训练目标与评估总分不是同一量

对长度 L 的完整回合，优化目标和回报为：

```text
J(theta) = E[sum_t gamma^t r_t]
G_t = r_t + gamma r_(t+1) + gamma^2 r_(t+2) + ...
loss = -(1/(100B)) sum_(episode i) sum_t
       gamma^t log pi_theta(a_it | x_it) detach(G_it - b)
```

`G_t` 内的折扣从 t 开始计时；外面的 `gamma^t` 是为了与从回合开始折扣的 J 保持一致。先在时间维求和，再对完整回合取平均。除以固定正数 100 只改变损失/梯度尺度，训练配置中保留这个选择。使用 Adam，梯度总范数裁剪为 10；有效学习率和调整理由在正式预算记录中。

基础版令 `b=0`，没有减 episode 均值、减 batch 均值或含减均值的 z-score。因此它确实是无 baseline 的基础蒙特卡洛策略梯度。CartPole 的 gamma 是 .95，Pong 的 gamma 是 .99。

评估分数是原始完整回合总奖励 `R=sum_t r_t`，没有折扣。一个好看的训练折扣回报不能直接替代评估总分。Pong 的稀疏奖励可能很晚才出现；严格的 `.99^t` 会压低晚期得分的权重，这能解释学习困难，但不能在正式结果里偷偷改目标。

网络权重采用 PyTorch `nn.Linear` 默认初始化，初始化前设置 `torch.manual_seed`：CartPole 两种方法同为 101，Pong 两种方法同为 202；没有预训练权重。Adam 的默认 betas=(.9,.999)、eps=1e-8、weight_decay=0，PyTorch 固定为 2.14.1。四组各 512 次更新，梯度范数均未超过裁剪阈值 10，实际触发裁剪次数都为 0。网络都只有一个 64 单元隐藏层。CartPole 输入四维物理状态，隐藏层 Tanh。Pong 输入真实游戏 RGB 图像：按 PDF 裁剪、降采样、去背景，得到 80×80 二值图；用当前帧减上一帧提供运动信息；每次 reset 第一帧差为全零。Pong 隐藏层 ReLU，两个输出映射为环境动作 `[2,3]`，即 RIGHT/LEFT。没有换成 RAM 输入。

## 4. 为什么收集轨迹不保留计算图

完整 Pong 回合较长。若每一步保存带梯度的输出，内存会持续增长。代码在 `inference_mode` 下采样，把图像差分以 int8 放在 CPU；更新时逐块重新算 log-prob，块大小 512，累积所有梯度后只做一次 optimizer step。

关键约束是：从某一批采样开始，到这批最后一块反传结束，策略参数始终不变。否则重新计算的 log-prob 就不再对应采样策略，基础 on-policy REINFORCE 公式会失去保证。代码直到完整批次全部反传完才更新，避免这个问题。评估同样禁用梯度。

## 5. baseline：来自上一批，不能依赖当前动作

本作业选择标量 EMA baseline；它在当前批次采样前已经确定：

```text
target_k = sum_(i,t) gamma^t G_it / sum_(i,t) gamma^t
b_(k+1) = 0.9 b_k + 0.1 target_k
advantage_it = detach(G_it - b_k)
```

初值 `b_0=0`。先用 `b_k` 完成当前批的采样和策略更新，再根据本批回报计算下一批的 `b_(k+1)`。当前动作无法影响已经固定的 `b_k`，因此 baseline 的期望梯度项为零。这里没有 value network，也没有 critic loss。

baseline 主要影响**梯度估计的方差**。它不保证最终均分更高，也不保证评估奖励的标准差更小。精确小实验中 b=2 降低梯度方差约 71.02%，但 b=8 反而提高方差，二者都保持期望梯度不变。这正说明要把算法机制与最终游戏表现分开理解。

如果减去包含当前样本的 batch 均值，均值会依赖当前动作。一个四样本精确实验中，期望梯度缩成原来的 0.75。不能把这种含 baseline 的中心化称为基础版。实际使用先前批 EMA 避开这种自依赖；EMA 也不是严格的最优方差 baseline。

## 6. 环境完整回合与 2,000 次评估

当前官方注册名为 `ALE/Pong-v5`，对应题目 Pong-v5。实际动作含义、版本和配置都保存在环境记录中。Pong `frameskip=4`，sticky action 概率 .25，mode/difficulty 都为 0；没有 FIRE/NOOP 包装器，没有按 rally 或 +1/-1 得分伪终止，也没有为加速缩短回合。自然游戏结束或官方 108,000 ALE 帧上限才完成回合。CartPole 使用官方 500 步 TimeLimit。

每个正式模型先按预算训练、冻结最终 checkpoint 并保存 SHA-256，再使用独立于训练/调参的种子运行 500 个完整环境回合。四个模型合计至少 2,000 回合。全部方法都从动作分布采样，保持可比；没有用 argmax 改变评估策略，也没有看 500 次最终结果反复挑 checkpoint。

每行日志记录 seed、episode ID、原始总奖励、折扣回报、长度、自然终止/时间限制标记、累计步数、耗时和 checkpoint。 `terminated` 和 `truncated` 在 CartPole 第 500 步可以同时为真，统计时按自然终止仅、时间上限仅、两者同时三个互斥类别计数；不能简单相加两个标记把 500 回合误读成 502。训练日志的 `sampling_policy_update` 对应采样时的更新前策略，`checkpoint` 的逻辑标签不是声称保留了每个中间模型文件；评估使用实际冻结文件哈希。均值按 500 条原始奖励计算；标准差使用样本标准差 `ddof=1`，即分母 `n-1`。这不是均值的标准误。

## 8. 如何知道算法对，而不仅是“能运行”

每个验证都遵循：目的 → 理论预期 → 运行方法 → 实际定量结果 → 解释。具体数值和命令见 `docs/shuttle_method.md`、`docs/rl_validation.md` 与 JSON。

班车验证包括：独立递归遍历极小决策树（40 个状态/期数组合误差 0）、8 个手算边界（误差 0）、无到达确定性闭式对照（误差约 `1.80e-9`）、Bellman residual（VI 约 `9.41e-11`、PI 约 `9.09e-13`）、有限/无限尾界（实际差约 `4.94e-9` 小于界 `6.84e-8`），以及从不发车策略的独立成本参考。VI/PI 互相一致只能辅助验证，不能排除共同建模错误，所以需要手算与独立 oracle。

策略梯度验证包括：三步奖励 [1,2,3] 的手算 RTG；八条 Bernoulli 轨迹精确求期望梯度；刻意漏 `gamma^t` 的有偏反例；自动微分和有限差分比较；实际小步更新提高 J；实际 CartPole 完整 45 步回合的前十步状态/动作/奖励/回报跟踪。后者只展示十行，但没有把回合截成十步。

实际生产路径还直接调用 `src.rl.update()`：精确枚举的真实参数更新约 `9.86875e-5` 与理论一致；极端 chunk size=1 与独立单图更新的参数最大差约 `2.98e-8`；真实 CartPole 批次保存/恢复后下一批轨迹完全一致、参数差为 0，baseline 完全一致；合成图像检查去背景、负帧差和不修改原图。恢复证据针对完整更新边界的 CPU，不声称未完成回合或 CPU/MPS 位级一致。

baseline 验证包括：固定 baseline 保持期望梯度、不同值降低或提高方差、动作相关 baseline 的偏差、当前 batch 均值的自依赖，以及 advantage detach 后 baseline 没有梯度。这些数学小实验检验机制，不能替代大游戏的正式训练。

## 四组真实实验汇总

四个正式模型各训练 4096 个完整回合，之后各用冻结模型评估 500 个完整回合；合计 16,384 个训练回合、2,000 个正式评估回合。所有图 1–11 均来自保存的真实数值。以下统计可从 CSV 重新计算。

| 模型 | 首100原始 R | 末100原始 R | 首100折扣 J | 末100折扣 J |
|---|---:|---:|---:|---:|
| CartPole 基础 | 36.580 | 453.460 | 15.3171 | 19.8185 |
| Pong 基础 | -20.500 | -20.510 | -1.4373 | -1.1791 |
| CartPole baseline | 39.490 | 404.090 | 15.7873 | 20.0000 |
| Pong baseline | -20.530 | -19.980 | -1.4323 | -0.2470 |

| 模型 | 评估 n | 均值 | 样本 SD | 范围 | 完整环境步数 |
|---|---:|---:|---:|---|---:|
| CartPole 基础 | 500 | 143.678 | 125.834 | [11, 500] | 71,839 |
| Pong 基础 | 500 | -20.534 | 0.706 | [-21, -17] | 509,716 |
| CartPole baseline | 500 | 423.592 | 83.414 | [95, 500] | 211,796 |
| Pong baseline | 500 | -19.806 | 1.046 | [-21, -14] | 496,818 |

Pong baseline 相比基础版的最终均分提高 0.728，原始奖励样本 SD 增加约 0.341；两种策略的 500 回合全是负分，因此不能说已经解决 Pong。Pong 基础版末 100 回合原始总分几乎不变，但折扣目标改善，说明完整游戏得分与严格时间折扣目标需要分别报告。baseline 版的折扣 J 从 -1.4323 改善到 -0.2470，比原始分数的变化更明显。

冻结 baseline 策略上各 32 个配对轨迹的真实梯度协方差迹：CartPole 从 1.59872559 降至 2.45244e-10，比率 1.534e-10；Pong 从 0.04728198 降至 0.02545847，比率 0.538439，即降低约 46.16%。这测量的是同一策略、同一批轨迹下的估计器方差；Pong 最终奖励 SD 仍更高，正好展示两种“方差”不同。参数未更新、检查点未改变，诊断种子也独立于正式 500 回合。32 回合证据精度有限，不能推广到所有训练种子。

独立均匀随机策略各 32 回合作为描述性对照：CartPole 均值 20.34375、样本 SD 8.29539；Pong 均值 -20.59375、样本 SD 0.712079。它们不属于四个正式评估直方图，也没有用于选择 checkpoint。真实 Pong trace 在 seed 92000000 下完整运行 859 步、原始总分 -20；第 93 个零基决策首次奖励 +1，对 J 的贡献为 .99^93=0.392711，而完整 J=-0.295926。前十步立即奖励虽为 0，RTG 仍包含之后得分；reset 差分非零像素数为 0，重放的十步输入完全一致。

## 已完成的 CartPole 实际读图结论

基础版 4096 回合训练多次达到 500 步后再次崩落，最后 100 回合训练均值 453.46，但按预定预算冻结的最终模型 500 回合评估均值只有 143.678，样本 SD 125.834。最近 100 回合是多个先前策略采样的混合，最后一次 Adam 更新在最后批轨迹采样后才执行，可能改变策略；不能因为之前某段表现好，就用最终评估去反选那个 checkpoint。

相同训练 seed、网络、预算和评估规则下，baseline 最终均值 423.592，样本 SD 83.414。其 500 回合结束类别是自然终止仅 311、时间上限仅 187、两标记同时 2，合计 500。这个 seed 下 baseline 更好，但单个训练 seed 不能推出普遍结论。

CartPole 的严格折扣目标趋近 `1/(1-.95)=20`。100 步的折扣回报已约 19.8816，500 步几乎是 20，因此长生存之间很大的原始分数差异也可能只有很弱的折扣梯度信号。真实 32 回合梯度诊断里，保存的 baseline 接近 20，去掉了大量近常数回报带来的噪声；极大的样本方差下降不能直接等同于更大的最终总分。

## 9. 结论的边界与再给三个月的工作

单个训练种子不能分离训练随机性与方法本身的效果。匹配 500 个评估种子改善比较，但不会变出多训练种子的统计证据。严谨表述是“这些冻结策略在这些真实回合里的表现”，而非“baseline 普遍更好”。若学习失败，报告必须保留曲线、尝试、预算与可能原因。
