2 Value and Policy Iteration (30 points)
Consider the shuttle dispatching problem, where shuttles are sent to move passengers waiting at a station.
At each time step/decision epoch, an agent decides whether or not to dispatch a shuttle depending on
the number of customers waiting for the service. A standard shuttle dispatch problem has the following
parameters:
• K = The capacity of a shuttle if it is dispatched,
• At = A random variable giving the number of customers arriving during time interval t.
• cf = The cost of dispatching a shuttle.
• ch = The cost per customer left waiting per time period (incurred after dispatch).
Given K = 15, cf = 100, ch = 2 and assuming that At follows U nif{1, 2, 3, 4, 5}, model the problem as
a Markov Decision Process and solve it using:
a) Enumeration (with time period T = 500). Plot the optimal value function at time 0 versus number of
customers waiting.
b) Value iteration (T = ∞). Plot optimal value function versus number of customers waiting.
c) Policy iteration. Plot optimal policy versus number of customers waiting.
You can assume that number of people in station cannot exceed 200. Use discount rate γ = 0.95. If you
make any other assumption, please state it in your report.
